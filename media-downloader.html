    למה MediaDownloader Pro

    פשוט, מהיר ובנוי נכון

    מנוע yt-dlp

    מבוסס על yt-dlp, כלי הקוד הפתוח המוביל להורדת מדיה, שמתעדכן כל הזמן מול שינויים בפלטפורמות.

    עד 4K, ב־MP4 שמתנגן בכל מקום

    וידאו ושמע ממוזגים ל־MP4 (H.264/AAC כשאפשר), או שמע בלבד ב־MP3 באיכות הגבוהה ביותר.

    התקדמות בזמן אמת

    אחוזים, מהירות וזמן שנותר — וגם מתי השרת ממזג או ממיר את הקובץ.

    פרטיות

    בלי הרשמה ובלי מעקב. קבצים נמחקים מהשרת אוטומטית אחרי 15 דקות, וההיסטוריה נשמרת רק אצלך.

    שרת מאובטח

    רק פלטפורמות מאושרות, הגבלת קצב לכל משתמש, מגבלת גודל קובץ ו־CSP קשוח.

    שימוש הוגן

    לשימוש אישי, לתוכן שמותר לך לשמור. תוכן פרטי או כזה שדורש התחברות לא נתמך.

    7 ימים של Premium חינם

    האפליקציה לאנדרואיד

    לוחצים "שיתוף" ב־TikTok או ב־Instagram, בוחרים MediaDownloader, והסרטון אצלכם. עם Premium: הורדות ללא הגבלה, עד 4K ו־MP3.

    לעמוד האפליקציה באייפון

    הפעלת השרת

    ההורדות רצות על שרת Node.js קטן. אפשר להריץ אותו עם Docker או ישירות:

    docker build -f media-downloader/Dockerfile -t media-downloader .
docker run -p 8080:8080 media-downloader
# → http://localhost:8080
