# LangQuest · לומדת שפה מדוברת

לומדה אינטראקטיבית בעברית לשפה מדוברת ומעשית לחו״ל — דגש על שמיעה, הגייה, זיהוי צלילים ופירוק פונטי.
HTML/CSS/JS בלבד, בלי build ובלי שרת backend. ההתקדמות נשמרת ב־LocalStorage.

## איך לפתוח

```bash
cd langquest
python3 -m http.server 8080
# http://localhost:8080
```

> זיהוי דיבור (מיקרופון) דורש הקשר מאובטח — `localhost` או HTTPS — ודפדפן תומך (Chrome / Edge).
> בדפדפנים בלי זיהוי דיבור הלומדה עוברת אוטומטית להערכה עצמית / בחירת תשובה.

## מה ממומש לפי המפרט

| סעיף במפרט | מימוש |
|---|---|
| 2א · קריינות + בחירת מבטא | Web Speech TTS, דירוג אוטומטי של קולות Natural/Neural/Online; מבטא לכל שפה (🇺🇸/🇬🇧, 🇪🇸/🇲🇽) ובחירת קריין ידנית בהגדרות |
| 2ב · שליטה בקצב | מצב רגיל + מצב צב 🐢 ‏50%–70% (ברירת מחדל 60%) — `rate` של ה־TTS משמר את גובה הצליל |
| 2ג · פירוק הברות | כל מילה מפורקת להברות, תעתיק עברי מנוקד לכל הברה, וסימון ההברה המוטעמת בכתום |
| 2ד · מקראה עוקבת | הדגשה מילה־אחר־מילה לפי אירועי `boundary`; גיבוי בתזמון לפי מספר הברות לקולות שלא שולחים אירועים. לחיצה על מילה → הקראה איטית + פירוש |
| 3 · מחזור 4 השלבים | 👂 שמיעה וזיהוי → 🐢 תרגול איטי (כולל מילה־אחר־מילה וחזרה קולית) → 🎮 משחק (צליל←תמונה · השלמת מילה · הרכבת משפט) → 🎙️ בדיקת דיבור עם ירוק/אדום וציון דיוק |
| 4 · גיימיפיקציה | מפת מסע (✈️ 🏨 🍽️ 🛍️ 🚑) עם פתיחה הדרגתית · 🔥 רצף יומי על 5 דקות למידה פעילה · 👑 Audio Boss לכל תחנה · 📒 אוסף ביטויים עם Spaced Repetition (Leitner: ‏1→3→7→14→30 ימים) |
| פרופיל ורמות | בהפעלה הראשונה: אילו שפות אני יודע ובאיזו רמה (בסיסי A1–A2 · בינוני B1–B2 · מתקדם C1–C2 · שפת אם), איזו שפה ללמוד ומה הרמה בה → קצב אישי (🐢 עדין · 🚶 רגיל · 🏃 מהיר · 🚀 ליטוש מבטא) שקובע מהירות מצב צב, תעתיק, תחנות פתוחות, דילוג על שלבים ורף ההגייה. מי שדובר שפה קרובה (למשל איטלקית → ספרדית) או שפה זרה נוספת מתחיל קצב אחד מהר יותר |
| תזכורות | שעה (עד 3 ביום) וימים קבועים, יעד יומי 3/5/10/15 דקות. התראת מערכת + באנר בלומדה בזמן שהיא פתוחה (גם בלשונית ברקע), ויצוא ליומן (`.ics` עם התראה, או Google Calendar) כדי לקבל תזכורת גם כשהלומדה סגורה |
| 5 · ארכיטקטורת שפות | `js/data.js` — רישום שפות; אנגלית וספרדית מלאות, צרפתית/איטלקית/גרמנית רשומות כ״בקרוב״ |

### ביטויים שהתקשיתם בהם נשמרים אוטומטית
טעות במשחק, ציון הגייה מתחת ל־70%, או 3 ניסיונות כושלים מול הבוס — הביטוי נכנס לאוסף ומתוזמן לחזרה.

## מבנה

```
langquest/
├── index.html
├── sw.js           # service worker להצגת התראות בלבד (בלי cache)
├── css/langquest.css
└── js/
    ├── data.js     # שפות · מבטאים · תחנות · ביטויים · תסריטי Boss
    ├── store.js    # LocalStorage: הגדרות, התקדמות, XP, רצף, אוסף SRS
    ├── audio.js    # TTS + קריוקי, בחירת קול, זיהוי דיבור וניקוד הגייה
    ├── ui.js       # רכיבים: קריוקי, חלון מילה, פירוק הברות, בדיקת דיבור
    ├── reminders.js # תזכורות: מתזמן, התראות, יצוא ליומן
    ├── onboarding.js # פרופיל שפות, רמות וקצב אישי
    ├── lesson.js   # מחזור 4 השלבים
    ├── boss.js     # שיחת Audio Boss
    └── app.js      # מפה, אוסף, הגדרות, ניווט, מעקב זמן יומי
```

## הוספת שפה

ב־`js/data.js` מוסיפים ערך ל־`LANGS` עם `status: 'ready'`, מבטאים (קודי BCP-47), ו־`stations` לכל אחת מחמש התחנות.
כל מילה נכתבת כמחרוזת אחת:

```
"token|פירוש|syl·la·bles|תַּעְ·תּוּק|stressIndex"
"croissant|קרואסון|crois·sant|קְרְוָוא·סָאן|1"
```

תור ב־Boss מפנה לאינדקס הביטוי שהלומד צריך לומר (`expect`) ולתשובת הדמות (`reply`).

## הערות ומגבלות

- **איכות הקול תלויה במכשיר**: הקריינות משתמשת בקולות שמותקנים בדפדפן/מערכת. ב־Edge ו־Chrome יש קולות Online/Natural איכותיים; אם אין קול למבטא שנבחר, יושמע קול בסיסי של אותה שפה. אין עדיין הקלטות אנושיות.
- **ניקוד ההגייה** מבוסס על התמלול של מנוע זיהוי הדיבור (התאמת מילים עם סבילות לשגיאות קטנות) — הוא מזהה מילים שלא נקלטו נכון, לא ניתוח פונמי מלא.
- **ה־Audio Boss** הוא שיחה מתוסרטת עם הבנת דיבור, לא מודל שפה חי. אפשר לחבר בהמשך LLM לשיחה חופשית דרך backend.
- התעתיק העברי הוא קירוב שמיעתי לדובר עברית ולא תעתיק IPA.
