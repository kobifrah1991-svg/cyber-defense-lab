# LangQuest · לומדת שפה מדוברת

לומדה אינטראקטיבית בעברית לשפה מדוברת ומעשית לחו״ל — דגש על שמיעה, הגייה, זיהוי צלילים ופירוק פונטי.
HTML/CSS/JS בלבד, בלי build ובלי שרת backend. ההתקדמות נשמרת ב־LocalStorage.

## איך לפתוח

```bash
cd langquest
python3 -m http.server 8080
# http://localhost:8080
```

> זיהוי דיבור (מיקרופון) דורש הקשר מאובטח — `localhost` או HTTPS — ודפדפן תומך (Chrome / Edge).
> בדפדפנים בלי זיהוי דיבור הלומדה עוברת אוטומטית להערכה עצמית / בחירת תשובה.

## מה ממומש לפי המפרט

| סעיף במפרט | מימוש |
|---|---|
| 2א · קריינות + בחירת מבטא | Web Speech TTS, דירוג אוטומטי של קולות Natural/Neural/Online; מבטא לכל שפה (🇺🇸/🇬🇧, 🇪🇸/🇲🇽) ובחירת קריין ידנית בהגדרות |
| 2ב · שליטה בקצב | מצב רגיל + מצב צב 🐢 ‏50%–70% (ברירת מחדל 60%) — `rate` של ה־TTS משמר את גובה הצליל |
| 2ג · פירוק הברות | כל מילה מפורקת להברות, תעתיק עברי מנוקד לכל הברה, וסימון ההברה המוטעמת בכתום |
| 2ד · מקראה עוקבת | הדגשה מילה־אחר־מילה לפי אירועי `boundary`; גיבוי בתזמון לפי מספר הברות לקולות שלא שולחים אירועים. לחיצה על מילה → הקראה איטית + פירוש |
| 3 · מחזור 4 השלבים | 👂 שמיעה וזיהוי → 🐢 תרגול איטי (כולל מילה־אחר־מילה וחזרה קולית) → 🎮 משחק (צליל←תמונה · השלמת מילה · הרכבת משפט) → 🎙️ בדיקת דיבור עם ירוק/אדום וציון דיוק |
| 4 · גיימיפיקציה | מפת מסע (✈️ 🏨 🍽️ 🛍️ 🚑) עם פתיחה הדרגתית · 🔥 רצף יומי על 5 דקות למידה פעילה · 👑 Audio Boss לכל תחנה · 📒 אוסף ביטויים עם Spaced Repetition (Leitner: ‏1→3→7→14→30 ימים) |
| פרופיל ורמות | בהפעלה הראשונה: אילו שפות אני יודע ובאיזו רמה (בסיסי A1–A2 · בינוני B1–B2 · מתקדם C1–C2 · שפת אם), איזו שפה ללמוד ומה הרמה בה → קצב אישי (🐢 עדין · 🚶 רגיל · 🏃 מהיר · 🚀 ליטוש מבטא) שקובע מהירות מצב צב, תעתיק, תחנות פתוחות, דילוג על שלבים ורף ההגייה. מי שדובר שפה קרובה (למשל איטלקית → ספרדית) או שפה זרה נוספת מתחיל קצב אחד מהר יותר |
| תזכורות | שעה (עד 3 ביום) וימים קבועים, יעד יומי 3/5/10/15 דקות. התראת מערכת + באנר בלומדה בזמן שהיא פתוחה (גם בלשונית ברקע), ויצוא ליומן (`.ics` עם התראה, או Google Calendar) כדי לקבל תזכורת גם כשהלומדה סגורה |
| שפת בסיס (ממשק) | עברית כברירת מחדל; שפת הדפדפן קובעת אוטומטית (עברית · English · العربية · Русский), וניתן לבחור במסך הראשון או בהגדרות. כיוון הדף (RTL/LTR), כל הטקסטים, תרגומי הביטויים, פירושי המילים ותרגומי דמות ה-Boss מוצגים בשפת הבסיס. התעתיק העברי המנוקד מוצג רק כששפת הבסיס עברית. שפת היעד לא יכולה להיות שפת הממשק |
| 5 · ארכיטקטורת שפות | `js/data.js` — רישום שפות; אנגלית וספרדית מלאות, צרפתית/איטלקית/גרמנית רשומות כ״בקרוב״ |

### ביטויים שהתקשיתם בהם נשמרים אוטומטית
טעות במשחק, ציון הגייה מתחת ל־70%, או 3 ניסיונות כושלים מול הבוס — הביטוי נכנס לאוסף ומתוזמן לחזרה.

## מסכים, PWA ואפליקציה

- **כל גודל מסך**: טלפון קטן (320px), טלפון לרוחב, טאבלט, מחשב (מפה + פאנל צד), מסכים גדולים; תמיכה ב-notch ובאזורים בטוחים.
- **PWA**: ניתן להתקנה מהדפדפן (כפתור 📲), עובד אופליין אחרי הפתיחה הראשונה.
- **APK לאנדרואיד** (Capacitor 8, `android/`): הקראה וזיהוי דיבור נייטיב, תזכורות כהתראות מערכת גם כשהאפליקציה סגורה, כפתור חזרה, אייקונים ומסכי פתיחה בכל הרזולוציות.
  - **בנייה אוטומטית**: GitHub Actions (`.github/workflows/langquest-android.yml`) בונה APK בכל שינוי — מורידים מ-Actions ← הריצה ← Artifacts.
  - **בנייה מקומית**: `npm install && npm run apk:debug` (דורש Android SDK + JDK 21).
  - **חתימה לשחרור**: יוצרים keystore (`keytool -genkey -v -keystore release.jks -alias langquest -keyalg RSA -keysize 2048 -validity 10000`) ומוסיפים ב-GitHub Secrets: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` — ה-workflow יבנה APK חתום ו-AAB לחנות.

המחירים והגדרות התשלום במקום אחד: `js/commerce.js` (`PLANS`, `CONFIG`).

**חיבור תשלומים (Stripe):**
1. ב-Stripe יוצרים 3 מחירים (חודשי/שנתי עם trial של 3 ימים, ו-lifetime חד-פעמי) ו-Payment Link לכל אחד. ב-Payment Link מגדירים כתובת חזרה: `https://<האתר>/index.html?session_id={CHECKOUT_SESSION_ID}`.
2. פורסים את שרת הרישיונות: `cd server && npx wrangler deploy`, ומגדירים `npx wrangler secret put STRIPE_SECRET_KEY` ו-`LICENSE_SECRET`; ב-`wrangler.toml` ממפים מזהי מחיר לתוכניות.
3. ממלאים ב-`js/commerce.js`: `CONFIG.checkout` (3 הקישורים) ו-`CONFIG.licenseApi`.
4. בדיקות השרת: `npm run test:server`.

עד שמגדירים — רכישה פועלת **במצב הדגמה ב-localhost בלבד**, מסומן בבירור.

> **Google Play:** רכישה דיגיטלית בתוך אפליקציה שמופצת ב-Play חייבת לעבור ב-Google Play Billing. ה-APK שמופץ מהאתר יכול להשתמש ב-Stripe; לגרסת Play יש להוסיף ספק חיוב של Play (למשל RevenueCat) מאחורי אותו `LQCommerce`.

## אתר המכירה

`site/index.html` — דף נחיתה בארבע שפות (עברית · English · العربية · Русский) עם צילומי מסך אמיתיים מהלומדה, יכולות, מורים, טבלת מחירים (מחוברת ל-`commerce.js` — כפתור תוכנית פותח את מסך הרכישה בלומדה), שאלות נפוצות, `privacy.html` ו-`terms.html` (טיוטות שדורשות השלמת פרטי מפעיל ובדיקה משפטית).
אחרי מיזוג ל-`main` אפשר לפרסם ב-GitHub Pages: `/langquest/site/` (האתר) ו-`/langquest/` (הלומדה).

## הוספת שפת בסיס (ממשק)

1. ב־`js/i18n.js`: מוסיפים ל־`UI_LANGS` (שם, דגל, `dir`) ומעתיקים את טבלת `STR.en` לשפה החדשה ומתרגמים.
2. ב־`js/data.js`: שדות `name_xx` / `desc_xx` / `label_xx` / `title_xx`, וב־`TRANSLATIONS.xx` תרגום לכל ביטוי ושורת Boss ופירוש לכל מילה. מה שחסר נופל חזרה לעברית.

## הוספת שפה ללימוד

ב־`js/data.js` מוסיפים ערך ל־`LANGS` עם `status: 'ready'`, מבטאים (קודי BCP-47), ו־`stations` לכל אחת מחמש התחנות.
כל מילה נכתבת כמחרוזת אחת:

```
"token|פירוש|syl·la·bles|תַּעְ·תּוּק|stressIndex"
"croissant|קרואסון|crois·sant|קְרְוָוא·סָאן|1"
```

תור ב־Boss מפנה לאינדקס הביטוי שהלומד צריך לומר (`expect`) ולתשובת הדמות (`reply`).

## הערות ומגבלות

- **איכות הקול תלויה במכשיר**: הקריינות משתמשת בקולות שמותקנים בדפדפן/מערכת. ב־Edge ו־Chrome יש קולות Online/Natural איכותיים; אם אין קול למבטא שנבחר, יושמע קול בסיסי של אותה שפה. אין עדיין הקלטות אנושיות.
- **ניקוד ההגייה** מבוסס על התמלול של מנוע זיהוי הדיבור (התאמת מילים עם סבילות לשגיאות קטנות) — הוא מזהה מילים שלא נקלטו נכון, לא ניתוח פונמי מלא.
- **ה־Audio Boss** הוא שיחה מתוסרטת עם הבנת דיבור, לא מודל שפה חי. אפשר לחבר בהמשך LLM לשיחה חופשית דרך backend.
- התעתיק העברי הוא קירוב שמיעתי לדובר עברית ולא תעתיק IPA.
